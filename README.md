# Instant Video & Picture Search Pro

## Deutsch

**Version 1.0.18 für Windows 10/11 x64.** Die kostenlose Anwendung für private und gewerbliche Nutzung findet Videos, Bilder und TXT-Dateien über einen lokalen Dateiindex. Gespeicherte Bestände bleiben offline durchsuchbar.

Version 1.0.18 ergänzt die automatische Laufwerkszuordnung beim Start, Suchprofile, Ausschlussbegriffe und Phrasen, global sortierbare direkte Treffer mit weiteren Ergebnisseiten sowie Datenbanksicherung und Wiederherstellung.

Entpacke das vollständige Portable-ZIP und akzeptiere beim ersten Start die Nutzungsbedingungen.

## English

**Version 1.0.18 for Windows 10/11 x64.** This free application for private and commercial use finds videos, pictures and TXT files using a local index. Saved collections stay searchable offline.

Version 1.0.18 adds automatic drive-to-index matching at startup, search profiles, exclusions and phrases, sorting and paging across direct matches, and database backup and restore.

Extract the complete portable ZIP and accept the Terms of Use when you first start the app.
