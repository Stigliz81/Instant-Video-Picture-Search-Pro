Privacy

Marius Walz is the controller for the project website and for handling enquiries. The postal and email contact details are above.

The application stores index data such as filenames, paths and metadata, together with settings, search history and favourites, on your computer or in storage locations you select for that purpose. Search and media analysis run on your computer. If you select network shares, Windows accesses that network location. Search and media analysis do not use AI content search, cloud synchronisation or telemetry to the publisher.

You manage folder selection, settings and saved search data on your computer. How long local data is stored depends on your use and when you delete it.

When you request an update check, the application fetches latest.json over HTTPS from GitHub Pages. GitHub receives the IP address and technical HTTP request data, including the update user agent. The request contains no search terms, index data, file paths or media. The check does not download or install a new application version.

GitHub Pages hosts the website. GitHub states that it logs visitor IP addresses for security. Website images, system fonts, stylesheets and scripts do not cause the site to request embedded third-party resources. The project website does not set its own analytics or advertising cookies. The legitimate interest in hosting and security is to provide a reachable and secure project website. The legal basis for hosting, security and the requested update check is Art. 6(1)(f) GDPR.

Access to GitHub Pages or GitHub Releases and use of PayPal or email may involve providers outside the EEA. GitHub describes the EU–US Data Privacy Framework for transfers to the United States and standard contractual clauses where applicable. GitHub explains retention, recipients and transfers in its privacy statement. When you choose to visit PayPal, PayPal provides its own privacy information.

External links open when you choose to follow them. These include GitHub Releases for downloads, PayPal for voluntary donations, and links to other projects and information. The provider then receives connection data and handles it under its own privacy terms. The project website does not embed a payment form. GitHub Pages · GitHub Privacy Statement

If you contact the publisher by email, the publisher and the email service process your address, message and necessary communication data to respond. The legal basis is Art. 6(1)(b) GDPR for necessary contract-related enquiries and Art. 6(1)(f) otherwise. Data is kept for as long as needed to deal with the enquiry, meet legal retention duties or establish or defend claims. Contact is voluntary. A reply may be impossible without the necessary details.

Subject to the GDPR, you have rights of access, rectification, erasure, restriction, portability, objection to processing based on legitimate interests, and complaint to a supervisory authority. Use the contact details above for privacy enquiries.
